# Fleet decoupling: Fonto standalone

Part of the fleet decoupling mission (levio → fonto → depona). Fonto now owns its AI, its published API, and its identity — no sibling app or `@joeybuilt/plexo-sdk` anywhere. Merges the work tracked in `docs/claude/fleet-decoupling/plan.md`.

## What changed (~93 files, +1,028/−3,183)

**Deleted (Plexo surface):** `lib/plexo.ts`, `lib/plexo-registration.ts`, `lib/plexo-vision.ts`, `lib/intelligence/adapters/plexo-{federated,unified}.ts`, `app/api/plexo/{data,events}`, `app/api/health/plexo`, both `components/plexo*` status components, obsolete unified-analyze test, `.claude/skills/plexo.md`.

**Added:**
- Per-user AI connections: `drizzle/migrations/0063_ai_connections.sql`, `lib/ai/connections.ts`, `app/api/ai/connections/route.ts`, `components/settings/ai-connections-section.tsx`, `scripts/provision-ai-default.mjs` (seeds "LiteLLM Auto" as the default connection for a user).
- Encryption home: `lib/crypto/secret-box.ts` (single encryption path; `integrations/tokenCrypto.ts` now delegates). Encrypted at rest per AGENTS.md hard rule.
- Published peer API: `app/api/peer/v1/{data,events}` behind app-owned service keys (`lib/peer/service-keys.ts`).
- Jex manifest: `public/.well-known/jex.manifest.json` + route `app/.well-known/jex.manifest.json/route.ts`.
- `lib/intelligence/prompts.ts` — prompts as versioned config (AI Features rule).

**Rewritten:** conformance guard (inverted to zero-plexo; asset-projection whitelist rule kept), intelligence registry/client/ports/anthropic adapter, vision sidecar (`FONTO_VISION_URL` only), `.dependency-cruiser.cjs`, `next.config.ts`, `instrumentation.ts`, `processAsset` + ~20 call sites, health route, app-shell, settings page, `verify.yml`, `.env.example`/compose examples, `sync-agents` mirrors, `CHANGELOG` `[Unreleased]`.

`@joeybuilt/plexo-sdk` removed from `package.json` + lockfile; zero `PLEXO_*` reads.

## Graceful degradation (no 503 anti-pattern)

- No AI connection and no env fallback → typed `CapabilityUnavailableError {port:"jex/Completion"}`, core flows continue.
- Vision sidecar unset → vision degrades (`intelligence.vision:false`), ingest continues.
- plexo-vision deliberately stays STOPPED in the acceptance environment.
